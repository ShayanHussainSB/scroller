# Scroller icon

A manga panel: paper inside a black frame, focus lines bursting toward a slanted ink **S**, and speed lines streaking past it, because the page is scrolling. Black and white only; red stays reserved for "scrolling right now".

- `icon.svg`: the full art, used for 48 px and up.
- `icon-small.svg`: 16 and 32 px. The focus and speed lines drop out so the S stays sharp in the toolbar.

The S is set in Bricolage Grotesque (`extension/fonts/bricolage.woff2`), so open these files somewhere that font is installed or loaded. The PNGs in `extension/icons/` were rendered from them at 16, 32, 48 and 128 px.
